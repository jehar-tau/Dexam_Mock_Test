# 10. Completion plan: every Learn programme to be built

Written 15 November 2026, when the owner set the goal of finishing the
Learn section, built only with Opus 5.5 and pushed to main topic by topic.
This file is the definition of "complete". When every row below says
**Done**, the Learn section is complete.

Each programme gets four tiers: Foundations, Exam standard, Exam hard
(matched to the owner's question bank where one exists) and Mastery (a
timed set with exam marking). Rules for building and merging are in
`05-build-playbook.md` and `09-topic-bank-map.md` section 9.5.
