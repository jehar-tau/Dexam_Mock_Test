# Product design thinking

Slug `product-design` · method pattern · deck `productDeck` (`pd-`) ·
source: the owner's design-thinking theory guide (method only; the briefs
are our own).

Status: all four tiers **Built** (16 November 2026).

Steps taught: users (specific groups and the constraint the setting puts on
them), context (the one physical variable, e.g. ramp slope), the pain point
under a stated demand, features that trace to constraints, material and
ergonomics (one-word justification, stability, part count), annotation, and
the order of the design process. Ends with the formula checklist: User +
Context + Problem + Feature + Material + Label.
