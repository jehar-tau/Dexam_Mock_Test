## Marking reminder

- **NAT:** +4 correct, 0 wrong.
- **MSQ:** +4 for all correct; +1 per correct option if no wrong option is selected; −1 for any wrong option.
- **MCQ:** +3 correct; −0.71 wrong.
- Unattempted = 0.

The app calculates these rules automatically. A production exam should apply them on the server, with the marking scheme stored per paper and per section.

The four drawing prompts are in `drawing-prompts.md`. They are not auto-scored; use the rubric and self-review sheet. Part B evaluation is a human judgment task, so the rubric should be applied consistently and, ideally, by more than one evaluator for high-stakes work.
